# unitQ

> unitQ is an AI-powered customer feedback and product quality platform. It unifies feedback from support tickets, app-store reviews, social channels, and surveys into a real-time quality signal (the unitQ Score), and offers products including monitorQ, supportQ, metricQ, socialQ, competeQ, interviewQ, and agentQ. unitQ names a User Feedback Upload API (ingest feedback data) and a Data Enrichment API (attach user attributes, platform details, and KPIs such as CSAT/NPS to feedback); the API reference lives in the login-gated help center.
